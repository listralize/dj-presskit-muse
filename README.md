# UNK DJ - Press Kit

Press Kit oficial do UNK DJ, produzido por Listralize.

## Tecnologias

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Desenvolvimento

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Deploy (Coolify / Docker)

```sh
docker build -t unk-dj-presskit .
docker run -p 80:80 unk-dj-presskit
```
